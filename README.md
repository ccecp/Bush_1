## Publicare pe GitHub Pages
1. Creează un repository nou.
2. Încarcă toate fișierele și folderul `audio` din această arhivă în rădăcina repository-ului.
3. Deschide **Settings → Pages**.
4. La **Build and deployment**, selectează **Deploy from a branch**.
5. Alege branch-ul `main` și folderul `/ (root)`.
6. Salvează. GitHub va genera adresa site-ului.
